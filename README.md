# ✨ Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website designed to showcase professional skills, educational background, projects, research publications, and contact information.

The portfolio features a dark/light theme, smooth animations, interactive elements, and a clean user interface to create an engaging experience across desktop, tablet, and mobile devices.

## 📌 Features

- **Modern UI:** Clean, professional, and responsive portfolio design.
- **Loading Animation:** Animated preloader when opening the website.
- **Interactive Background:** Particle-network animation with mouse interaction.
- **Typing Animation:** Dynamic typing effect for professional roles.
- **Profile Section:** Personal introduction and profile image.
- **About Me:** Professional summary and educational timeline.
- **Technical Skills:** Animated skill bars and floating skill elements.
- **Projects Showcase:** Interactive project cards with 3D hover effects.
- **Research Publications:** Dedicated section to showcase research work.
- **Contact Section:** Contact form with email integration.
- **Dark/Light Mode:** Switch between different visual themes.
- **Scroll Animations:** Smooth section transitions and reveal effects.
- **Scroll Progress:** Visual indicator showing page scrolling progress.
- **Animated Counters:** Dynamic statistics and number animations.
- **Back to Top:** Quick navigation to the top of the website.
- **Resume Download:** Dedicated button to download the resume.
- **Responsive Design:** Optimized for different screen sizes.

## 💻 Getting Started

Follow these steps to run the portfolio locally.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/my_portfolio.git
```

### 2. Navigate to the Project

```bash
cd my_portfolio
```

### 3. Add Personal Assets

Add your profile photo and certificate inside the `images` folder.

Make sure the filenames match the references used in the HTML file.

### 4. Run the Website

Open `index.html` in your browser.

You can also use the VS Code Live Server extension for local development.

## 🌐 Deployment

This portfolio can be deployed for free using:

- GitHub Pages
- Netlify
- Vercel

### GitHub Pages Deployment

1. Push the project files to your GitHub repository.
2. Open repository Settings.
3. Navigate to Pages.
4. Select Deploy from a branch.
5. Select the `main` branch and `/root` folder.
6. Click Save.

Your portfolio will be published using GitHub Pages.
